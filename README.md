# Дорожная карта ОП — ДГУ

Интерактивная карта обучения по учебному плану: семестры сверху вниз, модули плана колонками,
стрелки — связи между дисциплинами. Клик по блоку открывает карточку: семестры, з.е., часы по видам занятий,
формы контроля и связи. Все данные о дисциплинах взяты только из PDF учебного плана.

Сейчас собрано: **09.03.02 ИСИТ**, профиль «Технологии разработки безопасного ПО ИС», набор 2026.

**Смотреть:** https://samur000.github.io/plan-isit/

## Что отдавать на сайт

| Файл | Зачем |
|---|---|
| `docs/embed.html` | Фрагмент для вставки в страницу dgu.ru (режим HTML в Bitrix). Шрифт Geometria берётся из шаблона сайта. |
| `docs/index.html` | Та же карта отдельной страницей. Её же показывает GitHub Pages. На домене dgu.ru сама подключает Geometria, на других — системный шрифт. |

Все стили изолированы внутри `#dgu-roadmap`, внешних библиотек нет.

## Откуда данные

`source/pdf/isit_09.03.02.pdf` — учебный план (тот же файл, что на dgu.ru):

| Страницы PDF | Что берём | Файл |
|---|---|---|
| 1 | направление, профиль, ФГОС, год набора, протокол Учёного совета | `source/curation_isit.json` → `meta` |
| 4–5 | структура плана, группы дисциплин по выбору | `source/plan_isit.json` |
| 6–9 («КУРС 1–4») | полные названия, часы по видам занятий, з.е., формы контроля и недели по семестрам | `source/courses_isit.json` |
| 10 («Сводные данные») | з.е. по блокам плана для шапки и сверки | `source/courses_isit.json` |

В `source/curation_isit.json` кроме паспорта программы задано, какие модули плана идут в какую колонку (`tracks`),
и стрелки (`edges`: `[откуда, куда]`). Стрелок в плане нет: они составлены по порядку семестров и содержанию дисциплин,
их стоит проверить на кафедре.
Сборка сверяет сумму з.е. по каждому семестру со сводными данными плана.

## Пересборка

```bash
python3 -E scripts/extract_plan.py source/pdf/isit_09.03.02.pdf source/plan_isit.json
python3 -E scripts/extract_courses.py source/pdf/isit_09.03.02.pdf source/courses_isit.json
python3 -E scripts/build.py
```

Нужен PyMuPDF (`pip install pymupdf`).

Просмотр: `python3 -m http.server 8765 --directory docs` → http://localhost:8765/

GitHub Pages публикует папку `docs/` из ветки `main` — после пересборки достаточно закоммитить и запушить `docs/`.
