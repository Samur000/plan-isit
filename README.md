# Дорожная карта ОП — ДГУ

Интерактивное «дерево» обучения по учебному плану: семестры сверху вниз, направления (ветки) колонками,
стрелки — связи между дисциплинами. Клик по блоку открывает карточку: семестры, з.е., часы, аттестация,
связи и ссылки на РПД/ФОС из ЭОР.

Сейчас собрано: **09.03.02 ИСИТ**, профиль «Технологии разработки безопасного ПО ИС», набор 2026.

**Смотреть:** https://samur000.github.io/plan-isit/

## Что отдавать на сайт

| Файл | Зачем |
|---|---|
| `docs/embed.html` | Фрагмент для вставки в страницу dgu.ru (режим HTML в Bitrix). Шрифт Geometria берётся из шаблона сайта. |
| `docs/index.html` | Та же карта отдельной страницей. Её же показывает GitHub Pages. На домене dgu.ru сама подключает Geometria, на других — системный шрифт. |

Все стили изолированы внутри `#dgu-roadmap`, внешних библиотек нет.
Ссылки ведут на файлы `dgu.ru/files-oop/...` и `oop.dgu.ru/sved/files-oop/...`.

## Откуда данные

- `source/pdf/isit_09.03.02.pdf` — учебный план (числа извлекаются автоматически, суммы сверены: по 30 з.е. в семестре, 240 всего).
- `source/eor/isit_16456.json` — ЭОР (`oop.dgu.ru/api/Discipline/GetDisciplineByProfileId?profileId=16456`): названия и ссылки на РПД/ФОС.
- `source/curation_isit.json` — **правится вручную**: к какой ветке относится дисциплина (`assign`),
  короткие подписи (`short`), стрелки (`edges`: `[откуда, куда]`).
  Стрелки составлены по порядку семестров и содержанию дисциплин — их стоит проверить на кафедре.

## Разбор плана

Блок `review` в `source/curation_isit.json` — разбор плана по рабочим программам из ЭОР (на 17.11.2026):
повторы, устаревшее содержание, дисциплины вне профиля, нарушенный порядок и вариант замен без изменения объёма.

- `flags` — замечания к конкретным дисциплинам: жёлтая метка на карточке дерева и блок в модальном окне.
  Ключ — код дисциплины или варианта выбора, `kind` — тип замечания из `kinds`.
- `sections`, `stats`, `plan` — секция «Разбор плана» под деревом.
- На странице есть переключатель «Замечания по плану»: он оставляет на дереве только отмеченные дисциплины.

Если на публичную страницу dgu.ru разбор выводить не нужно, удалите ключ `review` и пересоберите —
метки, переключатель и секция исчезнут.

## Пересборка

```bash
python3 -E scripts/extract_plan.py source/pdf/isit_09.03.02.pdf source/plan_isit.json
python3 -E scripts/build.py
```

Нужен PyMuPDF (`pip install pymupdf`). Скрипт сборки предупредит, если связь указывает на несуществующий код
или дисциплина не попала ни в одну ветку.

Просмотр: `python3 -m http.server 8765 --directory docs` → http://localhost:8765/

GitHub Pages публикует папку `docs/` из ветки `main` — после пересборки достаточно закоммитить и запушить `docs/`.

## Как добавить ИБ (10.03.01)

Файлы уже лежат: `source/pdf/ib_10.03.01.pdf`, `source/eor/ib_16455.json`, `source/curation_ib.json`.
Извлеките план в `source/plan_ib.json` и допишите `"source/curation_ib.json"` в `PROGRAMS` в `scripts/build.py` —
на странице появится переключатель направлений.
